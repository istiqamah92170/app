Kelola data ATP dan konten media

Tempel atau unggah data dalam format JSON. Struktur ATP dapat memiliki jumlah semester, bab, dan pertemuan berapa pun. Untuk setiap TP, isi bagian lesson agar media pembelajarannya tampil mendalam.

Catatan: Template ini tidak mengubah dokumen Word/PDF menjadi ATP otomatis. Dokumen dapat dibantu AI untuk dikonversi ke struktur JSON ini, lalu hasilnya diperiksa guru sebelum diterapkan.
Data yang diterapkan disimpan di browser perangkat ini. Gunakan tombol Unduh JSON sebagai salinan cadangan sebelum mengganti perangkat atau membersihkan data browser.
